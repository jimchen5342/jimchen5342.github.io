1. id: 流水號，從 1 開始
2. kana
3. roma: 
  例一: わたし => wa ta shi
  例二: ちゃん => cha n
  例三: 長音要用 ā ī ū ē ō
  例四: 短促音要和下一個字併在一起
4. kanji: 如沒有就不要
5. accent: 補上重音，格式為字串，如沒有就不要
6. mean: 中文解釋
註1: 如有音讀或訓讀區別，只要是訓讀，請在 mean 後面加註 (訓讀)
註2: 請轉成 json 檔下載
